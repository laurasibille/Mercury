# Component Inventory

- DemoBanner: dark promotional strip, desktop only.
- Sidebar: product header, switcher, main navigation, bookmarks.
- Topbar: brand/search/actions/avatar; compact responsive variant.
- QuickActions: five desktop pills, two mobile controls.
- BalanceCard: graph/table modes and period popover.
- AccountsSection: account list, create and overflow actions.
- CreditCardModule: balance meter, available amount, autopay.
- BillPayModule: status counters and inbox summary.
- InvoicingModule: overdue, paid and open summaries.
- MoneyMovement: month selector, money-in/out summaries and sources.
- TransactionsTable: tabs, sortable-looking headers, mock rows.
- TryMercuryPanel: raised desktop overlay and collapsed responsive bar.
