# Interaction Patterns

- Segmented controls use a bordered 40px container with active indigo icon.
- Pills use 32px height, full radius and 12–16px horizontal padding.
- Popovers use 8–12px radius, white surface and soft dual shadow.
- Table rows receive a subtle hover fill and preserve 48–56px height.
- Icon buttons use 32px circular hit areas.
- Disabled controls retain shape at reduced opacity.
