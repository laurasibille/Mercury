# Technical Stack Analysis

- Source is a React single-page application with CSS modules and inline SVG icons.
- Source font is Arcadia Text; clone uses Inter because Arcadia files are not supplied.
- Clone uses Next.js App Router, React client state, TypeScript, Tailwind CSS v4 and CSS variables.
- Lucide React supplies generic interface icons; Mercury mark is recreated as a reusable inline SVG.
- Data is local and deterministic. No source APIs, authentication or banking operations are used.
