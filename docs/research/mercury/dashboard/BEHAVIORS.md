# Mercury Dashboard Behaviors

- Primary actions: local buttons; external navigation is out of scope.
- Balance view: graph/table segmented toggle. Table state shows current, available, pending transfers and pending deposits.
- Period menu: pill opens a vertical list of seven periods with a checkmark on current selection.
- Private mode: toggles monetary values to masked dots and back.
- Transaction tabs: select local mock datasets without navigation.
- Month controls: previous month changes label and data; next is disabled for current month.
- Try Mercury: desktop panel expands/collapses; category pills switch local task lists. Tablet/mobile use a collapsed bottom bar.
- Mobile sidebar: opened from menu button and dismissed locally.
- Hover: pale surface fill on ghost controls and table rows.
- Focus: visible 2px indigo ring.
- Transitions: color/background 160ms ease-out; raised panel height 300ms cubic-bezier(0, 1, .2, 1).
